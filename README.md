# So‘zni top

Yashirin so‘zni harflar bo‘yicha topish o‘yini. HTML, CSS va JavaScript bilan yozilgan, kutubxonalarsiz.

Muallif: Mamadaliyev Ramzbek, 26-161.

## O‘yin

- Turkum tanlanadi: mevalar, hayvonlar, shaharlar, kasblar, texnologiya yoki hammasi.
- Ekranda so‘zning ta’rifi va harflar soni ko‘rinadi.
- Harf so‘zda bo‘lsa ochiladi, bo‘lmasa bitta yurak ketadi. 6 ta xatodan keyin o‘yin tugaydi.
- «Yordam» bitta harfni ochadi va 5 ball oladi. Har so‘zda 2 ta yordam bor.
- Ball, seriya va rekord brauzerda saqlanadi.

O‘zbek alifbosidagi O‘, G‘, SH va CH bitta harf sifatida hisoblanadi.

## Dizayn

- «Liquid glass» uslubidagi shaffof panellar va harakatlanuvchi rangli fon.
- Yuqorida Dynamic Island ko‘rinishidagi xabar paneli.
- Harflar ochilganda aylanish, xatoda silkinish, g‘alabada konfetti animatsiyasi.
- Natija pastdan chiqadigan oynada ko‘rsatiladi.
- Telefon uchun moslangan, tizimdagi yorug‘ yoki qorong‘i rejimga moslashadi.

## Fayllar

- `index.html` — sahifa tuzilishi
- `style.css` — dizayn va animatsiyalar
- `words.js` — so‘zlar va ta’riflar
- `script.js` — o‘yin mantiqi

## Ishga tushirish

`index.html` faylini brauzerda oching. Kompyuter klaviaturasidan ham yozish mumkin: `C` — ch, `W` — sh, `Enter` — keyingi so‘z.
